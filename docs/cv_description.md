# CV Description

## Version A — one line
Built a reproducible Python pipeline for multimodal cultural evidence modeling using real Metropolitan Museum of Art data, image/text embeddings, similarity analysis, clustering, networks, and temporal patterns.

## Version B — three bullets
- Collected and validated open museum records through The Met Collection API, preserving provenance, licensing flags, missingness, and reproducible caches.
- Extracted frozen visual and multilingual semantic representations and compared cross-cultural similarity, alignment, clustering, and object-similarity networks.
- Developed a Streamlit Cultural Evidence Explorer and documented computational observations as candidates for humanities interpretation rather than causal historical claims.

## Version C — research experience
Developed a computational humanities pilot that structures real museum collection records as multimodal cultural evidence. The Python workflow integrates API-based data collection, quality assessment, image validation, OpenCLIP and multilingual text feature extraction, cosine similarity, dimensionality reduction, exploratory clustering, NetworkX similarity networks, and temporal summaries. A Streamlit interface supports provenance-aware exploration of objects and candidate cross-context relationships. The project extends prior interests in cultural heritage and multimodal human-centered research toward reproducible, large-scale cultural analysis.
