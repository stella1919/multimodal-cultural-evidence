# Dataset Card

**Dataset:** Cross-Cultural Buddhist Object Dataset — Pilot  
**Source:** The Metropolitan Museum of Art Collection API  
**Version/date:** generated at runtime; see `results/run_summary.json`  
**Selection:** de-duplicated Met object records with accessible image and object-page URLs; no synthetic records.  
**Fields:** museum metadata plus researcher-derived `cultural_context`, `text_for_embedding`, dates and embedding coordinates.  
**Licensing:** metadata and images follow the source institution's open-access/public-domain indicators; images are for research and educational display.  

Known biases include The Met's collection bias, uneven metadata richness across regions, the simplified pilot taxonomy, search-keyword bias, and the fact that digital objects cannot stand for complete historical context.
