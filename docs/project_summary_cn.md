# 项目摘要（申请材料草稿）

本项目将文化遗产数据库中的图像、文本、年代、地域与文化属性转化为可追溯的多模态文化证据，探索计算方法如何服务于跨文化人文学术问题。项目围绕三个问题展开：不同文化语境的佛教文化对象是否存在可计算的视觉与语义相似性；视觉相似与文化语义是否一致或错位；整合年代、地域与文化属性后，能否发现值得进一步考察的跨地域关联与演化模式。

研究使用 The Metropolitan Museum of Art Collection API 的真实开放数据，经过 API 缓存、去重、字段质量评估、图像验证与规则透明的文化语境分类，形成 Cross-Cultural Buddhist Object Dataset—Pilot。方法包括 OpenCLIP 视觉表征、多语言文本嵌入、余弦相似度、降维、聚类、相似性网络与世纪尺度时间分析。计算结果被定义为 potential patterns 与 candidate cases，而不是历史因果或传播证明。

项目体现了我从文化遗产与多模态人本研究走向大规模计算文化分析的研究转向，并以“computational discovery + humanities interpretation”为核心原则。
